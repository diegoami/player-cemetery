# Gameplay evidence ownership

Owner instruction,2026-11-16: Borg Cemetery is the canonical home for gameplay
incident/death analysis, scenarios and behavioral/counterfactual trial reports.
Publish analysis in diegoami/borg-cemetery and link it here. This repository
retains original human/mixed recordings, raw export archives, build identities,
and local play/save state. Preserve published archive hashes and git history.
Do not duplicate canonical reports or put source-policy fixes in an evidence PR.
Use isolated copies for replay and human alternatives; never overwrite original
recordings or an active human play/save branch. Clearly label reloads and other
branches of one life; they are not independent population samples.
